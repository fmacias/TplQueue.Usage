# Core License

`TplQueue.Core` is the execution kernel of the TplQueue line.

## Public package status

- the NuGet package is public
- the repository itself remains private
- package-based consumption is supported through the published binaries

## License model

`TplQueue.Core` is not distributed under MIT. It uses package-specific binary-use license terms.

That means:

- the official binaries can be evaluated and integrated under the published package terms
- source-code access is separate
- private repository access is separate
- modification and redistribution rights are not implied by the package alone
