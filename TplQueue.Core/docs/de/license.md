# Core Lizenz

`TplQueue.Core` ist der Ausfuehrungskern der TplQueue-Linie.

## Oeffentlicher Paketstatus

- das NuGet-Paket ist oeffentlich
- das Repository selbst bleibt privat
- package-basierte Nutzung wird ueber die veroeffentlichten Binaries unterstuetzt

## Lizenzmodell

`TplQueue.Core` wird nicht unter MIT verteilt. Es gilt ein eigenes Binary-Use-Lizenzmodell fuer das Paket.

Das bedeutet:

- die offiziellen Binaries koennen unter den veroeffentlichten Paketbedingungen genutzt werden
- Quellcodezugang ist separat
- privater Repository-Zugang ist separat
- Aenderungs- oder Weiterverteilungsrechte ergeben sich nicht automatisch aus dem Paket
